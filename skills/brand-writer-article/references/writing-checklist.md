# 写作过程中的同步清单

以下每一项在写作过程中同步检查，避免写完再返工。四层自检是写完后跑的正式检查，本清单是边写边用的预防。

## 开篇

- [ ] 从一个具体的、当下的事件/场景切入（不是宏大叙事）
- [ ] 第一句话让读者产生"然后呢？"的冲动
- [ ] 不用教科书式开头（"在当今 AI 快速发展的时代"、"随着技术的不断进步"）

## 正文

- [ ] 每个核心观点有具体的人/场景/细节/数据支撑
- [ ] 知识点用"聊着聊着顺手掏出来"的方式，不用"下面我来科普一下"
- [ ] 偏离主线的段落后面加"扣主线句"拉回来
- [ ] 技术机制都转成生活化类比，不堆术语
- [ ] 提到 AI 工具/产品用具体名（Claude Code / ChatGPT / Gemini），不说"某个 AI 工具"

## 节奏

- [ ] 长短句交替，不连续 3 句以上相近长度
- [ ] 全文至少 3 次一句话独立成段制造"断裂"感
- [ ] 用疑问句做节奏的"刹车和转向"

## 标点与格式

**用官方调性写**（品牌号宽松）：
- [ ] 可用冒号、四级小标题、重点加粗
- [ ] 但不要大段加粗（超过 2 行）
- [ ] 不要连续 bullet 超过 3 个

**模仿博主写**（严格）：
- [ ] 禁用破折号 `——`（改用逗号或句号）
- [ ] 禁用英文双引号 `""`（改用 `「」` 或不加）
- [ ] 不用小标题（除非"N 条心得"类）
- [ ] 冒号按博主风格判断（差评风格一般禁用）

## AI 味词实时防御

（边写边避，不要到自检才改）

**完整词表与替代写法以 `brand-writer-check/references/banned-words.md` 为单一事实来源**。写作时重点避免以下类别（详见该文件 🔴 第一级）：

- 结构型套话：`从 X 到 Y`、`不仅 X 还 Y`、`在 X 的当下` 等
- 情绪叠加词：`不得不说`、`毋庸置疑`、`妥妥的` 等
- AI 标志性修辞：`犹如 / 宛若`、`堪称 X 的典范` 等
- 过度技术腔：`赋能`、`打造闭环`、`跃迁` 等
- 逻辑/叙事 AI 腔：`说白了`、`本质上`、`换句话说`、`意味着什么`、`不可否认`、`众所周知`、`综上所述`、`首先...其次...最后` 等

命中即自检 🔴 必改。如要新增产品专属豁免，在 profile 加 `## 豁免词` section 登记（详见 banned-words.md）。

## 人物与情绪

- [ ] 用"我当时就愣住了"而不是"我当时很震撼"（体感记忆 vs 知识性描述）
- [ ] 人物画像要有具体细节（年龄/职业/场景），让读者"感觉到体温"
- [ ] 情绪表达用具体行为代替形容词（"一下子不知道说什么"而非"震惊到说不出话"）

## 结尾

- [ ] 按产品档案「写作偏好」的结尾规范收尾
- [ ] 故障排查 / 排雷避坑 → 必含客服邮箱
- [ ] 产品科普 / 调查实验 / 体验 / 现象解读 → 收在价值或洞察上
- [ ] 最后是否有"回环呼应"（前文伏笔收回来，让文章成为作品而非信息流）
