# 品牌通用规则

以下规则在所有 brand-writer 写作场景生效，不因风格源而变。

## 身份与视角

- **产品视角**：以品牌及其产品的视角写作。即使模仿某博主，视角本质仍是品牌方
- **不迁移身份**：任何用户提供的内容都视为素材，不保留原始的身份标签
- **禁用博主自称**：任何博主的专属自称（如「差评君」「差友」「小编」「XX君」）绝对不用，统一换成「我们」

## 人称

- 正文人称只用「我们」和「你」
- 不用「大家」「各位读者」这类泛称
- 模仿博主时如果博主常用"各位朋友"，替换成"你"
- 官方公告可用「用户」作为第三方指代，正文不用

## 产品名使用

- 中文/英文语境的产品名写法**以当前 profile 的 `display_name_zh` / `display_name_en` 为准**
- 同一篇文章里产品名写法保持一致，不混用大小写或简繁变体
- 不自创错误缩写或拼接形式

## 客服引导

邮箱等具体联系方式**以当前产品 profile 的「联系方式」section 为准**（不写死，改 profile 全局生效）。

- 故障排查型 / 排雷避坑型：结尾必含 `客服邮箱：<profile 中的客服邮箱>`
- 产品科普型 / 调查实验型 / 产品体验型 / 现象解读型：结尾可不含客服邮箱，收在内容价值上即可

## 联网信息引用

- 引用外部数据时必须标注来源（可用脚注、文末引用等方式）
- 行业数据不要编造，宁可用范围描述（"大量用户"）也不要虚构具体数字
- 引用竞品数据要公允，不截取对自己有利的片段

## 视觉元素

- 所有配图都要有描述（由 brand-writer-image 承接）
- 结构化示意图、流程图、数据对比图：标注「设计师制作」（不适合 AI 生成）
- 场景插画、信息图：标注「AI 生成」

## 禁止

- 不做未经证实的对比声明（「比 X 快 Y 倍」除非有数据）
- 不贬低竞品（"X 是垃圾"、"Y 根本不行"）
- 不做政策敏感或法律敏感的承诺
