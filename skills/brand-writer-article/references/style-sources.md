# 三种风格源

## 1. 用官方调性写

**数据源**：产品档案 `~/.claude/skills/brand-writer/profiles/<产品名>.md` 中的「写作偏好」「品牌规则」「核心痛点库」。

**核心规则**：
- 严格遵守产品档案的人称规则（focusflow 为例：只用「我们」和「你」）
- 应用档案中的标题风格（口语化 / 疑问句 / 感叹句 / 明示利益点）
- 开篇按档案规则：先痛点场景，再定心丸，不从品牌视角强推
- 类比原则：技术机制必须转化为生活化类比，不堆砌术语；类比每次重新找
- 节奏：短句为主，操作指南不超过 3 招
- 结尾：故障排查/排雷类必须含客服邮箱；产品科普类收在产品价值上不强推客服

**什么时候用**：
- 写官方公告（系统维护、功能上线、价格调整等）
- 写产品科普（某功能怎么用、某机制为什么这样设计）
- 写故障排查和排雷（教用户自救）

## 2. 模仿博主写

**数据源**：风格报告 `$BRAND_WRITER_HOME/style-reports/<博主名>.md`

**核心规则**：
- 启动时必须读完整份风格报告
- 应用报告中的「推荐词组清单」：在转场、表达判断、拉近距离时主动使用
- 严格禁用报告中的「专属自称」（博主的自称必须换成「我们」）
- 遵守报告的「开篇方式」「节奏」「语气」
- 品牌规则仍优先：即使博主原文里有某些自称或写法，产品档案的「品牌规则」覆盖
- 模仿的是风格而不是身份——不要假装自己就是那个博主

**什么时候用**：
- 合作稿（跟某博主合作，需要博主风格感）
- 投稿（给博主账号投稿）
- 蹭风格（想借某博主的文风写一篇，但实际是自己家的稿）

## 3. 自由写

**数据源**：无。用户现场给的要求 + AI 自己的判断。

**核心规则**：
- 无预设风格，按题材和读者自然写
- 品牌规则仍必须遵守（人称、禁用自称、产品名约定）
- 用户说"就写轻松点"或粘贴一段参考样本时，作为一次性参照
- 自检时只跑 L1 最基本的 AI 味词扫描

**什么时候用**：
- 临时实验（尝试一种新风格）
- 找灵感（让 AI 先写一版，看感觉）
- 不重要的内部内容

## 风格源决定自检等级

| 风格源 | brand-writer-check 运行时跑哪些 L1 清单 |
|---|---|
| 用官方调性写 | 通用禁用词 + 品牌号宽松版（冒号/小标题/加粗均可用） |
| 模仿博主写 | 通用禁用词 + 模仿博主严格版 + 博主专属禁用词（来自 style-report） |
| 自由写 | 仅通用禁用词 |

## 局部借鉴（V2 新增，主 + 借鉴 模型）

风格源不再是纯三选一。用户可在选完主风格源后，额外指定 0-N 个「局部借鉴」：
- 维度：`title` / `opening` / `pacing` / `ending` / `interaction`
- 每个借鉴 = (博主, 维度) 对
- 来源：已有风格报告的五维度分析

### 应用规则
- 主风格源决定整体基调
- 借鉴维度覆盖对应章节的风格表达
- 当某维度无借鉴时，完全走主风格源

### 示例
主风格：`official`（focusflow 官方调性）
借鉴：
- (差评, title) — 5 个标题候选按差评的标题套路
- (槽值, opening) — 开篇钩子用槽值的打开法

效果：整体是官方调性，但标题和开篇有外部博主的风味。
