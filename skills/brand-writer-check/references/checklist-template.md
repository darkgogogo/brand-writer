# 自检报告模板

brand-writer-check 产出的标准格式。V2 变更：写入独立文件 `articles/<标题>/self-check-report.md`，不再追加到主 md。

```markdown
---
tags:
  - brand-writer/content/self-check
created: YYYY-MM-DD
article: <标题>
checked_at: YYYY-MM-DD HH:MM
passed_layers: L1/L2/L3/L4
style_source: <official / mimic_blogger / free>
blogger: <博主名，仅 mimic_blogger 时>
archetype: <原型名>
---

# Self-Check Report: <标题>

> 生成时间：YYYY-MM-DD HH:MM
> 风格源：<官方调性 / 博主名 / 自由>
> 文章原型：<原型名>
> borrowed：<博主A/维度X, 博主B/维度Y 或 "无">

## L1 硬性规则扫描 [✅/❌]

### 🔴 必改（强禁 + 博主专属）
- 第 N 段命中 "XX" → 建议替换为 "YY"
- ...（零命中则写 "✅ 无命中"）

### 🟡 请复核（条件禁）
- 第 N 段有 "XX"，语境判断：<可保留 / 建议改>

### 🟢 提示（弱禁 + 引用豁免）
- "XX" 全文出现 N 次（阈值 X），<建议降频 / 可接受>
- 已跳过扫描的 blockquote：L10, L23, L45

**阻塞状态**：🔴 零命中 ✅ → L2 开工 / 🔴 N 命中 ❌ → L2 不开工，先修

## L2 风格一致性 [✅/❌]

- 开头（L2-1）：✅/❌
  - 是否从具体事件切入：✅/❌
  - 第一句是否有"然后呢？"冲动：✅/❌
  - 有无教科书式开头：✅/❌
  - borrowed(opening) 应用：✅/❌/不适用
- 节奏（L2-2）：✅/❌
  - 长短句交替：✅/❌
  - 独立成段"断裂"≥3 次：✅/❌（共 N 次）
  - 扣主线句：✅/❌
  - 疑问句节奏：✅/❌
  - 小标题使用合理：✅/❌
  - borrowed(pacing) 应用：✅/❌/不适用
- 口语化（L2-3）：✅/❌
  - 推荐词组使用数：N 个（要求 ≥X）
  - borrowed(interaction) 应用：✅/❌/不适用
  - 故意打破：✅/❌
  - 自嘲/承认不足：✅/❌
  - 情绪标点：✅/❌
- 标点禁令二次确认（L2-4）：✅/❌

## L3 内容质量 [✅/❌]

- 知识输出方式（L3-2）：✅/❌
- 文化升维（L3-3）：✅/❌/不适用
- 对立面与同理心（L3-4）：✅/❌

  - 诉求 2：...

  - 遗漏点：<具体列出或"无">

  - 姿态：✅/❌
  - 心流：✅/❌（断点位置：...）
```
