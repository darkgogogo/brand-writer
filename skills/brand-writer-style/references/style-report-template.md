# 风格报告模板

新分析产出的报告必须套用此模板。保存路径固定为 `$BRAND_WRITER_HOME/style-reports/<博主名>.md`。

```markdown
---
tags:
  - brand-writer/content/style-report
name: <博主名>
platform: <wechat|xhs|x|weibo|crossplatform>
generated_at: YYYY-MM-DD
source_articles_date_range: YYYY-MM to YYYY-MM
sample_count: <分析样本数>
---

<常见几种开头套路及示例>

### 结尾习惯
<常见收尾方式、是否有固定结束语>

## 叙事结构层
### 行文节奏
<长短句分布 / 独立成段频率 / 口语打断密度>

<数据驱动 / 故事驱动 / 类比驱动 / 实测驱动>
```
