# 平台差异化 patterns（v1.0 预留接口，不实施）

v1.0 只做通用社媒文案。本文件记录未来分平台扩展时的主要差异点，方便 v2 继承。

## 小红书

- 钩子必须在第一行完成
- 标题党 + 反差爆款套路
- emoji 密度更高（每句一个起步）
- 适合的钩子：个人经历 / 踩坑故事 / 对比前后
- Hashtag 少而精，3-5 个最相关
- 排版用空行分段，像笔记

## X / Twitter

- 280 字符硬上限
- 长文用 thread，每条 280 内
- 第一条是 hook tweet，必须有停顿感
- emoji 节制使用（过多掉权重）
- Hashtag 1-2 个足够
- 英文为主

## 微博

- 140 字以内最佳
- 话题 # XX # 放开头
- 吐槽/观点类适配好
- emoji 适量
- 可以 @ 相关账号
- 图文配合

## 朋友圈

- 不允许外链直接点击，所以钩子要够强让用户主动问
- 短句 + 大量空行
- 个人视角比品牌视角效果好
- 不写 hashtag

## 公众号推送语

- 50 字以内
- 上面一行 hook，下面一行说清价值
- 不用 hashtag

---

**实施建议（v2）**：skill 接受 `--platform=小红书` 参数，根据平台应用对应 pattern。Caption 和 hashtag 按平台生成，不是一份套所有。
